#  Finance Tools Python Module

This project provides a Python module with 10 personal finance functions, such as EMI, SIP, RD, FD calculators and more. Each function includes input validation and is accompanied by unit tests.

## Files

- `finance_tools.py` — Financial calculators
- `test_finance_tools.py` — Unit tests using `unittest`

## Functions

- `calculate_emi()`
- `calculate_sip()`
- `calculate_fd()`
- `calculate_rd()`
- `estimate_retirement_corpus()`
- `estimate_home_loan_eligibility()`
- `calculate_credit_card_balance()`
- `calculate_taxable_income()`
- `plan_budget()`
- `calculate_net_worth()`

##  How to Run

Step 1. Install Python 3. (if already installed python3 than not required to install again)
Step 2. Run tests:


python test_finance_tools.py
